# 📖 About The Project

**NearMe** is a location-based application designed to make it easier for users to discover useful places, businesses, and services around them.

The application allows users to search for a particular category, discover nearby locations, view useful place information, and open map directions.

Instead of manually searching through multiple platforms, NearMe brings location discovery into a simple and user-friendly interface.

---

# 🎯 Problem Statement

Finding nearby services can become difficult when users are unfamiliar with an area or need a service quickly.

For example, a user may need to find:

- 🏥 A hospital
- 💊 A pharmacy
- 🍔 A restaurant
- ☕ A cafe
- 🏦 A bank
- 🏧 An ATM
- ⛽ A petrol station
- 🛒 A store
- 🏨 A hotel
- 🔧 A service center
- 🎓 A school or college
- 🚗 A parking location

Users normally need to search, compare locations, check distances, and then open a separate map application for navigation.
